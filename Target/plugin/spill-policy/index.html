The size ladder

The same call has three possible bodies.

  1. 2 KB small the whole result reaches the model under the cap
  2. 40 KB truncated the model reads the head and the tail is cut at the cap
  3. 4.2 MB spilled the bytes move to a file and the model reads a locator /tmp/dsh-spill-7f2a

The stored object

Past the threshold the bytes move to a file and the model holds a locator.

The spilled file 4.2 MB

The bytes wait in /tmp/dsh-spill-7f2a; the prompt holds the locator.

The head of the file

The model reads the first lines; the rest waits in the store.

Without a store

The threshold has no exit, so the bytes stay in the prompt.

No store

Without a store the bytes cannot leave the prompt, and the call keeps its full body.
