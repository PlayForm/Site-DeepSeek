Core & Factory

hook-dsh-core ROLE: CORE

Hook @ DSH @ Core

The pure, dependency-free commonalities of the family: the section lists, the exclusion segments, the suppression composer, the policy loader, the refusal guard and the normalize/Stream machinery.

plugin-dsh-factory ROLE: FACTORY

Plugin @ DSH @ Factory

The family's first service: the ledger, the exclusion match, the discovery, the keep-list union, the gate set, the version-guarded fenced write, the wiring, the effects and the schema factory.

Governance

hook-dsh-governor-package ROLE: GOVERNOR

Hook @ DSH @ Governor @ Package

The silent package.json governor: hooks fs/observed, rewrites chain-governed pins to the effective registry's resolved versions, and runs the update stage as a detached, contained continuation.

hook-dsh-pinner-package ROLE: PINNER

Hook @ DSH @ Pinner @ Package

The silent package.json version pinner: hooks fs/observed and deterministically rewrites every ranged dependency version to its static version, protected by a pin-policy keep-list.

hook-dsh-governor-cargo ROLE: GOVERNOR

Hook @ DSH @ Governor @ Cargo

The Cargo.toml governor: the Rust-sided flavor of the package governor - surgical chain-pin rewrites on the raw TOML lines and cargo upgrade driven through the subprocess seam.

Normalize

hook-dsh-normalize-dash FLAVOR: DASH v0.0.1

Hook @ DSH @ Normalize @ Dash

Normalizes the unicode dash family to ASCII hyphen-minus in model output streams.

hook-dsh-normalize-quotes FLAVOR: QUOTES v0.0.1

Hook @ DSH @ Normalize @ Quotes

Maps the eight curly quote code points to their ASCII straight counterparts in model output streams.

hook-dsh-normalize-ellipsis FLAVOR: ELLIPSIS v0.0.1

Hook @ DSH @ Normalize @ Ellipsis

Replaces the horizontal ellipsis (U+2026) with the plain ASCII three-dot sequence in model output streams.

hook-dsh-normalize-spaces FLAVOR: SPACES v0.0.1

Hook @ DSH @ Normalize @ Spaces

Normalizes the unicode space family (Zs minus the ASCII space) to the plain space in model output streams.

hook-dsh-normalize-invisible FLAVOR: INVISIBLE v0.0.1

Hook @ DSH @ Normalize @ Invisible

Removes the zero-width/invisible character family (soft hyphen, zero-width spaces and joiners, bidi controls, BOM) from model output streams.

hook-dsh-normalize-fullwidth FLAVOR: FULLWIDTH v0.0.1

Hook @ DSH @ Normalize @ Fullwidth

Maps the entire FULLWIDTH FORMS range (U+FF01-U+FF5E) to its ASCII half-width counterparts in model output streams.

hook-dsh-normalize-file FLAVOR: FILE v0.0.1

Hook @ DSH @ Normalize @ File

The file-content normalizer: the normalize-file tool - the read, count, write pipeline applying all six transforms to a file already on disk, writing only when something changed.
