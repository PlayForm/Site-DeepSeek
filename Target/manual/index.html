01

The decisions

The dispatch, branch by branch

every branch below exists in Source/Function/Chunk.ts and Block.ts

  1. 01
    chunk.kind text-delta reasoning-delta tool-call-delta block-end other: identity
    condition switch (true) on Input.type
  2. 02
    scopes.conversation on: replace text off: identity
    condition Input.type === "text-delta" && Conversation
  3. 03
    reasoning flag on: replace text off: identity
    condition normalizeReasoning && scopes.reasoning
  4. 04
    raw marker marked: strip, count 0 unmarked: next gate
    condition argumentsDelta.startsWith('{"__normalize":false')
  5. 05
    toolArguments flag on: next gate off: identity
    condition normalizeToolArguments || scopes.toolInput
  6. 06
    name exempt exempt: identity else: replace arguments
    condition name === "edit" || "raw-write" || "normalize-file"
  7. 07
    replacement "...": three dots "": removed
    condition Replace(text, Ellipsis, Replacement)
  8. 08
    count > 0 yes: one ledger line no: no line
    condition after a normal completion

block-end runs the same gates on the assembled block: text and reasoning under the conversation scope, tool-call under the raw marker, the tool-args flag and the name exemption. block-start, usage and finish pass by identity.

03

The seam

Same seam, the order the waterfall runs it

six plain listeners · registration order · none prepends

  1. dash hook-dsh-normalize-dash
  2. quotes hook-dsh-normalize-quotes
  3. ellipsis hook-dsh-normalize-ellipsis
  4. spaces hook-dsh-normalize-spaces
  5. invisible hook-dsh-normalize-invisible
  6. fullwidth hook-dsh-normalize-fullwidth
  1. hook-dsh-normalize-dash: normalized N dash char(s) in one stream
  2. hook-dsh-normalize-quotes: normalized N quote char(s) in one stream
  3. hook-dsh-normalize-ellipsis: normalized 2 ellipsis char(s) in one stream
  4. hook-dsh-normalize-spaces: normalized N space char(s) in one stream
  5. hook-dsh-normalize-invisible: normalized N invisible char(s) in one stream
  6. hook-dsh-normalize-fullwidth: normalized N fullwidth char(s) in one stream

The run order is registration order: none of the six passes  prepend: true, so the profile's list decides. The one prepended listener this hook registers is its tools/post-execute  arm, a different seam. What the hook sees is what its predecessors left; what its successors see is what it wrote, because the wrapped stream is what the live UI and the durable transcript consume. Each module writes its own  logFile, so the proof is one line in that module's ledger.

01

The split

What the library owns, what the package owns

the package is small because the dispatch lives in the core

The shared library owns

  • the per-chunk dispatch (Stream/Chunk)
  • the block-end normalizer (Stream/Block)
  • the class-to-string replacer (Normalize/Replace)
  • the raw-marker strip (Stream/Strip)
  • the tool-results and step-batch decisions (Overpass, StepBatch)
  • the activation-line composer (Function/Activate)

This package owns

  • the Ellipsis class, U+2026 (Normalize/Ellipsis)
  • the replacement argument (Function/Replace)
  • the stream wrapper and its per-call raw tracking (Function/Normalize)
  • the two arm wire-ups (Function/Overpass, Function/StepBatch)
  • the config schema and defaults (Variable/Config)
  • the command and the ledger strings (Function/Command, Apply)

The EffectTS twin wraps the same core Gate with Effect's stream APIs; the seam, the config and the ledger string are unchanged.
