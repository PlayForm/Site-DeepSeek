Documentation/Design/Tool.md

The claim

The package's work is the calls it registers, so the machine is a register: the seam the names live on, the count of them, and one plate per call with what it takes and what it hands back. The first registered call takes the full width and the accent face, because it is the call a reader meets first, and the rest share the tracks below it.

The machine answers: **what can a caller call, and what does each call take and return?**

The borrow is a mechanic (a register is compared, not read), a geometry (two tracks and a full-width entry), and a state model (a call is registered or not, and the seam says where).

The copy

The section that mounts it prints the portrait's own title and `Plugs into ...`.

The machine prints, for each package it is mounted with, in this order: the seam label, the seam, the count, the calls label, the rule, one plate per call, and the note.

| +----------------------------------------------------------------+   |
| +------------------------------+  +------------------------------+   |
| | plate, one track             |  | plate, one track             |   |
| | Takes ....                   |  | Takes ....                   |   |
| | Returns ..                   |  | Returns ..                   |   |
| +------------------------------+  +------------------------------+   |
| +------------------------------+  +------------------------------+   |
| | plate                        |  | plate                        |   |
| | Takes ....                   |  | Takes ....                   |   |
| | Returns ..                   |  | Returns ..                   |   |
| +------------------------------+  +------------------------------+   |
| +------------------------------+                                     |
| | plate, alone                 |                                     |
| | the sixth call, alone        |                                     |
| +------------------------------+                                     |
+----------------------------------------------------------------------+
| NOTE   one paragraph, above a hairline, the measure                  |
+----------------------------------------------------------------------+

The sketch is 72 columns. The plates sit on two equal tracks, so five calls make an entry plate, two rows of two, and a final plate alone; the entry spans both tracks and is the only accent face on the shape. The band puts the seam at the left and the count at the right on one baseline, and the rule and the note both cap at the measure so a long sentence does not run the full width.

The machines

Tool adds the callable surface. Flow says what the package does to what passes, Service says what it provides to other plugins, and this says what a caller can type and what comes back.

| Neighbour on the same page | What it already says                        | What Tool must not say                                                                        |
| -------------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Flow                       | the order the package's work happens in     | the calls as stages                                                                           |
| Service                    | the methods a consumer calls on the context | the same names as a contract. A tool is called by the model; a service is called by a plugin. |
| Surface                    | every registration the README documents     | the calls again as surface rows                                                               |
| Configuration              | the knobs the tool reads                    | a take or a return as a knob                                                                  |

The seam is a field rather than a constant because the family registers two kinds of callable. A model-facing tool is registered on the tools seam; the cost family's surface is five verbs on the commands service, which the README says is not a tool and never enters the model context. Printing a command as a tool would be a lie a reader would catch, so the register names its own seam.

When the record is absent the machine renders nothing, so a portrait with a shape of tool and no register shows no band. There is no placeholder.

The decisions

| Decision                                 | The alternative rejected                        | Why                                                                                                                                                                        |
| ---------------------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A field of plates                        | A table with column heads                       | A call's takes and returns are sentences, not cells. In a table the longest sentence would set the column and the other four calls would read as short rows.               |
| The first call is the entry plate        | Six equal plates                                | The register has an entry: the call a caller meets first, and in the batch edit's case the one that opens the machine. Marking it is the register's own claim about order. |
| The entry takes the accent face          | Marking the entry with a badge                  | The accent face is the loudest surface on the shape, and the entry is the one call that deserves it. A badge would add a word to a name that already carries the action.   |
| The seam is a field                      | The constant `the tools seam`                   | The cost family's five verbs are commands, not tools. A constant would print a false seam on three of the five pages the machine is mounted on.                            |
| Two tracks, one under 720px              | One column always                               | The register is compared, and comparison wants the plates side by side. Under 720px the comparison is lost anyway, so the track collapses.                                 |
| The note is a paragraph under the plates | A seventh plate                                 | The note is about the register, not about one call. As a plate it would compete with the calls for the same grammar.                                                       |
| The hover rule only                      | A selected state on a plate                     | Nothing on the page is selectable and the site cannot invoke the tool. The rule says the call is addressable; a selection would promise a result.                          |
| The call count is the length of the list | A transcribed figure per package                | Two figures that can disagree will disagree. The band's count is `Call.length`, so the number and the plates are the same fact.                                            |
| The action is part of the name           | One plate per action, with the action as a fact | The action is the first field of the call and the tool is one tool. Splitting the name would print six tools where the source registers one.                               |

The history

### v1 - 2026-10-31

Built on 2026-10-31. Mounted on five package pages inside the portrait section: `/package/plugin-dsh-batch-edit`, `/package/plugin-dsh-cost`, `/package/plugin-dsh-cost-analysis`, `/package/plugin-dsh-normalize-file`, and `/package/plugin-dsh-workspace`. The page that proves the entry plate is the batch edit's, because its six calls make the entry span and the remaining five fill the tracks.

What is not drawn yet: the argument schemas the harness admits, which are the tool definitions rather than the calls, and the batch edit's typed job id path, which is one clause inside the commit plate's return rather than a fork of its own.
