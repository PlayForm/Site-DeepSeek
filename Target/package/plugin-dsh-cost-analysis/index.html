What it does

Reads the cost record and explains it.

Read the full description in the README.

The read-only analysis half: contribution and efficiency readings over the cost ledger

Plugs into the same SQLite file the cost plugin wrote, opened readOnly, and one analysis command.

  • A file credited with the cache saving its reads produced
  • Cost per surviving line, against the files read before the edit
  • Hunk lines, so a refactor reads next to a one-line fix
  • The money no file paid for, and the cache's share of a file
Seam the commands service: one command, over a ledger opened read-only
1 Calls

The plugin never writes a row, never creates a table, and registers no listener: the ledger keeps recording facts, and the judgement lives here.

  1. /analysis
    Takes
    a scope: file, project, client, model, or session
    Returns
    the metric rows of the enabled families, or the empty-ledger line when the scope has none

The ledger plugin already owns the cost name, so this half registers analysis; the five families it renders are credit, effectiveness, lines, overhead, and cache.
