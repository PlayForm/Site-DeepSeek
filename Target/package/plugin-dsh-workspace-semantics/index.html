What it does

Holds symbols, references, and dependencies.

Read the full description in the README.

The semantic model: the symbols, the references, the dependencies, and the rename plan

Plugs into the ctx.workspaceSemantics service, the fs/observed listener on the root context, and the optional lsp seam.

  • A file resolved lazily through its adapter
  • The references the graph asks for, and the symbols a caller asks for
  • A rename plan per adapter, or undefined
  • The lsp deepener, with the lexical list as the fallback
Service ctx.workspaceSemantics
6 Methods
3 Consumers
Methods
  1. resolve build the file's knowledge graph lazily through its adapter
  2. symbol one symbol of a resolved file
  3. references the reference list, deepened through the lsp seam when it exists
  4. rename the per-adapter rename plan
  5. adapt register an any-file adapter
  6. statistics the adapter count and the index size
Consumed by
  • plugin-dsh-workspace-graph, which asks for the references
  • plugin-dsh-workspace-reflect, which asks for the rename plan
  • the adapters the config names

Rule An extension with no adapter, or an adapter that cannot be certain, answers undefined plus one line, never a guessed plan.

Flow

The order this package's work happens in, with the branch that decides it inline, transcribed from the source and from the corpus where the corpus draws it.

  1. 01
    1. seam fs/observed, through the factory's Wire on the root context
    why

    The index trigger.

  2. 02
    branch the event carries the service's own actor, an excluded path, or a repeat version
    why

    Ignored, or dropped silently.

  3. 03
    drop the stale model for the path, and advance the monotonic revision
  4. 04
    1. seam resolve(path)
    why

    A lazily built knowledge graph, through the adapter for the file type.

  5. 05
    symbol, references, and the import dependencies
  6. 06
    deepen the references through the lsp seam, when the harness provides one
    why

    Same-file locations only, and every cannot-answer path falls back to the lexical list.

  7. 07
    rename(path, span, to): the per-adapter plan
    why

    The plan goes to the operate proposals, and the service never writes.

  8. 08
    branch no adapter, or an adapter that cannot be certain
    why

    undefined plus one line, never a guessed plan.

  9. 09
    store the workspace_semantics domain, and the ledger

Rule

The rename means something different per format, so the plan is the adapter's, and the service only refuses to guess.
