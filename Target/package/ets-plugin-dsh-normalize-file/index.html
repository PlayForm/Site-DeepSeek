What it does

Normalizes files already on disk.

Read the full description in the README.

The file-content normalizer: the family's six transforms, run on a file already on disk

Plugs into the normalize-file tool, the normalize-overpass command, and the factory's write executor.

  • One file read, the six tables applied, a per-character count
  • A write only when the count is above zero
  • A one-shot overpass over tool results or a step batch
  • One journal record per rewrite, and none for a no-op
Seam the tools seam for the file call, and the commands service for the one-shot overpass
2 Calls

One agent-chosen file per call: the tool reads, applies the family's six transforms with a count, and writes only when the count is above zero.

  1. normalize-file
    Takes
    a path
    Returns
    the count and the fresh version, or the unchanged result when the count is zero
  2. normalize-overpass
    Takes
    files, batch, results on or off, or scopes
    Returns
    the one-shot arm, armed for the next tool result or the next step

The six transforms are the dash, quote, ellipsis, space, invisible, and fullwidth tables, which is the same chain raw-write applies under its normalize flag.

Flow

The order this package's work happens in, with the branch that decides it inline, transcribed from the source and from the corpus where the corpus draws it.

  1. 01
    1. seam the normalize-file tool
    why

    One agent-chosen file per call.

  2. 02
    branch the files scope is off
    why

    The unchanged result returns, with no read, no write, and no line.

  3. 03
    resolve, read, and apply the six tables in order
    why

    Dashes, quotes, ellipsis, spaces, invisible, then fullwidth.

  4. 04
    branch the count is zero
    why

    Nothing is written, and no line is written either.

  5. 05
    write through the factory's executor, behind the version fence
  6. 06
    journal one normalized record, and append the count line
  7. 07
    store ~/.dsh/playform/plugin-dsh-normalize-file.log
  8. 08
    1. seam normalize-overpass, when a scope is armed
    why

    The tool-results arm prepends, and the step-batch arm rides agent/pre-step.

  9. 09
    fail a failed read, or an aborted write
    why

    No count line, and the tool reports the failure.

Rule

The rewrite is explicit and visible: the tool is the only trigger, nothing rewrites in the background, and a zero count writes nothing at all.
