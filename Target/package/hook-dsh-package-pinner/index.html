Default

What the harness does at this package's seam with none of the family installed, so the surface below has something to be a difference from.

The harness dispatches fs/observed as a emit and already has listeners there: fs-observation-policy, skill-filesystem, workspace-files.

An emit listener observes a fact that already happened, so the harness's own listeners can record it and cannot change it. This package records beside them, or acts on the world rather than on the payload.

Architecture

This plugin's own structure: the shape the portrait gives it, the facts its source documents, and the rule its flow obeys.

Shape

Plugs into the fs/observed event through the factory's Wire, and the direct-govern pin entry for package.json.

The silent pinner of every written package.json.

  • Strips one leading ^, ~, or = from the sections the config declares
  • Leaves a static version, a compound range, a wildcard, and a protocol dependency as authored
  • Unions the keep-list from the global policy file, the file's directory, and the nearest registry
  • Runs no update stage at all, so the pass is deterministic and its only write is fenced

Its shape machine belongs to Person.

Rule

One range prefix leaves and nothing else does: the pass is deterministic, there is no update stage, and every write goes through the version fence.
