Model Independence

Normalizers sit on the stream, not on the model.

Extensively battle-tested on DeepSeek V4 Flash & GLM 5.3 Flash token output streams. The dash, quotes, ellipsis, spaces, invisible and fullwidth flavors run on every token batch before it reaches your files; the file flavor re-normalizes what is already on disk; the governor and pinner keep every manifest pinned - regardless of which engine wrote the output.
