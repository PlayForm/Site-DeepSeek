The coverage on every batch, regardless of engine

The dash, quotes, ellipsis, spaces, invisible and fullwidth flavors run on EVERY token batch before it reaches your files. The file flavor re-normalizes what is already on disk. The governor and pinner keep EVERY manifest pinned - regardless of which engine wrote the output.

The 2026-10 widening is engine-independent too. The granular scopes arms and the normalize-overpass command are transforms on the harness's own waterfalls. The ccr compression is an engine-independent tool-result transform. The tool-coach's coaching is engine-independent behavior - NONE of them depend on which model produced the tokens.
