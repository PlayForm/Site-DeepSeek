Axis

The eight axes a reader actually turns, across the family. The exact field and default live on each package's page; this is the shape of the choice.

  • enabled 01 on: the listener stops returning the payload untouched
  • threshold 02 a smaller number: the hook acts sooner and on more results
  • replacement 03 another character or string: the normalizer writes what you name
The eight configuration axes, what each ships as, and what turning it does
Row Ships asTurn it
enabled off in most workspace packages on: the listener stops returning the payload untouched
log on off: the ledger line is not written, the behavior is unchanged
logFile a path under the profile a path of your own, or empty to keep the ledger in memory
domain the package's own name another domain: a second instance writes its own records
targets the tools the README lists a shorter list: the hook stops touching the tools you leave out
exempt the tools that must pass untouched a longer list: a tool you add here never reaches the hook's body
replacement the one the README documents another character or string: the normalizer writes what you name
threshold the size the README documents a smaller number: the hook acts sooner and on more results

Configure

Every knob hook-dsh-normalize-dash document, with its default.

Configuration of hook-dsh-normalize-dash
FieldTypeDefaultMeaning
log boolean true write the durable ledger file (volatile)
logFile string ~/.dsh/playform/hook-dsh-normalize-dash.log the normalize-dash ledger (volatile)
replacement string - the transform's only knob - hot-editable, the next stream picks it up with no remount (volatile)
normalizeReasoning boolean true normalize reasoning deltas and the assembled reasoning block too
normalizeToolArguments boolean false rewrite the tool-call argumentsDelta and the assembled ToolCallBlock.arguments when on - execution-critical raw JSON, the user's accepted risk
scopes object see below gates every arm independently; the whole object is volatile
scopes.conversation boolean true text-delta text + the assembled text/reasoning blocks
scopes.reasoning boolean true the reasoning-delta sub-gate (ANDed with normalizeReasoning)
scopes.toolInput boolean false the tool-call arguments arm (OR-ed with normalizeToolArguments)
scopes.toolResults boolean false the tools/post-execute arm
scopes.files boolean true inert in a stream flavor (present so one patch override drives the whole family)
scopes.batch boolean false the agent/pre-step arm
toolResultsExempt string[] read, edit, raw-write, normalize-file, ccr_retrieve, subagent, ask_user_question a tool result whose exec name is listed passes the tool-results arm by identity (volatile)
