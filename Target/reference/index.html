Term

One word per concept, borrowed from the code. Every page uses these words with these meanings.

package
One directory with a manifest: the npm artifact and its source.
plugin
A package that loads into the harness and adds tools or a bundle.
hook
A package that registers a listener on a harness event.
seam
The harness event a hook listens on, named area/event.
surface
What a package exposes to the harness: a listener, a tool, a service, a config.
knob
One field of a package's configuration, with its default.
lens
What the thing at a seam sees: the prompt, the text, the tool, the file.
effect
What a hook does at its seam: rewrite, record, or advise.
trace
The durable record a run leaves behind, one line per event.
ledger
The file one package writes about what it did.
release
One of the two trees: Classic, or the same packages rebuilt on Effect.
version
One line of the release: a number a package's changelog records.
bundle
One entry in the marketplace index: a package with its title and category.
category
The kind a bundle is listed under in the marketplace index.
node
One package drawn in the graph.
edge
One dependency drawn in the graph, from the dependency to the package that requires it.
term
One word this site defines, listed with its meaning on the reference page.
