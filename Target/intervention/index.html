Power

Three powers, one per dispatch mode. A page that claims more than the mode allows is a page that lies.

Change

A waterfall listener receives the payload and returns a changed one. This is the power that makes the model read a different turn, and the filled squares in the matrix are its uses.

Record

An emit listener sees a fact that already happened. This is the power that leaves an inspectable record, and the hollow squares are its uses.

Stop

A serial listener can end a turn but cannot rewrite it. No plugin here takes this power; the harness keeps it.

Record

Every plugin keeps a ledger line, and the page for each one says where.
