Conversation

What the model reads

The model never sees the harness, only the messages the log projects, and 4 seams can change them.

Role

One entry per part of the message the model reads, in the order it reads them. Each names the seam that can change it, the package that stands there, and what that package does.

  1. 01

    System

    The system prompt: the instructions, the step's admitted tool schemas, and every registered section, assembled fresh for each step.

    Seam
    • system-prompt/assemble
    Plugin
    • hook-dsh-live-containers
    • hook-dsh-tool-coach

    live-containers appends a live section at every assembly, and tool-coach appends a persistent coaching section once its ladder escalates.

  2. 02

    User

    The user messages: the batch the inbox delivers and the step claims, admitted as user/message before the request is frozen.

    Seam
    • agent/pre-step
    Plugin
    none

    unchanged

  3. 03

    Assistant

    The assistant messages: the text and reasoning the stream carries, settled as assistant/message and replayed as history.

    Seam
    • llm/stream
    Plugin
    • hook-dsh-normalize-dash

    normalize-dash rewrites the dash family in each delta and in the assembled block before the stream is settled.

  4. 04

    Tool

    The tool results: what the pipeline returns for each call, before the result becomes model content.

    Seam
    • tools/post-execute
    Plugin
    • hook-dsh-ccr
    • hook-dsh-tool-coach

    CCR replaces an oversized result with a preview and a retrieval marker, and tool-coach prepends a coaching note once a pattern repeats past its threshold.

Change

One conversation, before and after the family's seams. The same messages, in the order the request carries them.

CCR replaces the oversized read with a preview and a marker, live-containers adds a section to the system prompt, and normalize-dash rewrites the dash the model wrote.

Read

Every message above is a projection of the log, so the seam that changes it changes what the next request carries. The turn shows where the seams sit, and the tool pipeline shows how a result becomes model content.
