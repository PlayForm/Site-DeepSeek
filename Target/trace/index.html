Trace

What a run leaves

One turn writes 14 records. 11 survive a reload and 3  exist only while the process runs, which is the difference between a trace and a live view.

Record

Read top to bottom. The solid rail is a record the log keeps; the dashed rail is one the process drops when it ends.

  1. 01 turn/start durable a turn opened, before any input was claimed
  2. 02 agent/inbox/claimed live which message this turn took
  3. 03 step/start durable a step began, with its request controls
  4. 04 system/message durable the system prompt the model read
  5. 05 user/message durable the user turn as admitted
  6. 06 request/header durable the model, the effort, and the controls of the call
  7. 07 agent/assistant-stream live that the stream was live, and nothing after a reload
  8. 08 assistant/message durable the text the model produced, as settled
  9. 09 tool/call durable the call the model asked for
  10. 10 tool/result durable the result the model read next
  11. 11 step/end durable the step closed and its tool set was disposed
  12. 12 agent/status live the agent went idle
  13. 13 turn/end durable the turn closed, and the step count it took
  14. 14 session/flush durable the log was flushed to its file

Rule

The harness keeps the facts and drops the frames, and the family adds to the kept side.

Durable

A durable record is what the session log projects the next request from, so a reader who reloads the page sees exactly the messages the model saw.

Live

A live frame exists so a client can render the turn while it happens. It is not part of the log, and a hard stop before settlement leaves no trace of it.

Added

The family writes beside the log, not into it: a ledger line per hook, a journal per write, a cost row per event. That is what makes a run inspectable after the process ends.

Next

The same model, driven by a real trace, is the dashboard this site is built toward.

Every record above is a row the dashboard would read, and every ledger the family writes is a column it would add. The page is static today and the layout is the one a live source would fill.
