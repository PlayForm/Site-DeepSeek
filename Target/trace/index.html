Rule

The harness keeps the facts and drops the frames, and the family adds to the kept side.

Durable

A durable record is what the session log projects the next request from, so a reader who reloads the page sees exactly the messages the model saw.

Live

A live frame exists so a client can render the turn while it happens. It is not part of the log, and a hard stop before settlement leaves no trace of it.

Added

The family writes beside the log, not into it: a ledger line per hook, a journal per write, a cost row per event. That is what makes a run inspectable after the process ends.

Next

The same model, driven by a real trace, is the dashboard this site is built toward.

Every record above is a row the dashboard would read, and every ledger the family writes is a column it would add. The page is static today and the layout is the one a live source would fill.
