What it does

THE CATALOG'S ROLE AND SUMMARY

The routing-enforcer plugin: the silent model-route policy enforcement for the DeepSeek Harness. The user owns the model configuration (his policy files); the plugin enforces it on every subagent launch, model-independently - and the orchestrator is not even bothered.
