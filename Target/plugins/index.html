Guardians

2 PLUGINS
hook-dsh-ccr ROLE: COMPRESSOR

Hook @ DSH @ CCR

The tool-output compressor. Hooks the tools/post-execute waterfall. Replaces oversized results of the allow-listed target tools with a one-line type-aware preview plus a `<<<CCR:hash|type|size>>>` retrieval marker. Gated on thresholdBytes x the per-type multipliers, with auto-expand returning small results FULL. The original stays retrievable through the registered ccr_retrieve tool over the sha256-24 LRU store.

$ npm install @playform/hook-dsh-ccr@0.0.1
hook-dsh-tool-coach ROLE: COACH

Hook @ DSH @ Tool @ Coach

The terminal coach. Judges EVERY bash/pwsh call through a four-tier ladder - tier-0 ledger lines for every offense, tier-1 live-fetched coaching notes at the strike threshold, tier-2 a persistent system-prompt discipline section, tier-3 (opt-in) tools/pre-execute denies. Teaches the model to stop using the terminal for file content.

$ npm install @playform/hook-dsh-tool-coach@0.0.1

The shared waterfall: the overpass arm and the CCR marker guard

The ccr hook and the normalize flavors' tool-results overpass arm share the tools/post-execute waterfall: the overpass is the OUTERMOST prepend ({ prepend: true }), so the ccr compression sees the NORMALIZED bytes.
