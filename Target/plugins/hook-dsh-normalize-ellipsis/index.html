The Problem

WHY THE ELLIPSIS FLAVOR EXISTS

Text processors collapsing the typographic three-dot run into a single code point - U+2026, the horizontal ellipsis - while code blocks, commands and diffs expect three literal dots.

The collapsed typographic run is simply wrong downstream

Text processors collapse the typographic three-dot run into a single code point - U+2026, the horizontal ellipsis.

In code blocks, commands and diffs the collapsed form is simply wrong: three literal dots are what every parser, shell and search expects.

This flavor makes the ASCII spelling the one that reaches the transcript.
